# Numeración de la web (para pedir cambios)

Abre la web con `?numeros` al final para ver las etiquetas sobre la página
(móvil y escritorio). Se quitan con el botón **Ocultar números** o con `?numeros=0`.

- Inicio: https://carlosrope.github.io/fotografia-joel-godoy/?numeros
- Una categoría: https://carlosrope.github.io/fotografia-joel-godoy/catalogo/boda-en-playa?numeros

Ejemplo de pedido: «2.3: cambia el título por…», «quita 6.5», «en 7.2 haz las tarjetas más chicas».
Los números siguen el orden de la página de arriba hacia abajo.
